# Takeaway

No tool found ships a preloaded library of leotard blocks. Variation comes from one good block plus
design changes, so a single block with clear terms is a sound start. **[INFERRED]** FreeSewing Onyx
is the nearest thing to a systematic source, because it generates a pattern from body measurements.

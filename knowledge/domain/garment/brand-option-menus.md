# Takeaway

Brand configurators are **recolour-and-embellish menus over fixed styles**: you pick a back (or a
catalogue design), a neckline, fabric, leg cut and crystal coverage. **No reviewed storefront filters
by back, sleeve or neckline**; filters are size, price, collection and product type.[^styles] These
lists show the granularity real customers already choose at. Comparisons of the tools themselves
belong in [/domain/market/](/domain/market/about.md).

| Brand | Menu / filter | Exact options |
|---|---|---|
| GK Elite | Collection filters | `Adult Sizes`, `Child Sizes`, `Collection`, `Product Type`, `Price` (160.00-378.00 on special order)[^gk-special] |
| GK Elite | Infinite Possibilities (3 steps: back, neckline, then fabric and embellishments) | Backs: `Crisscross Back` (IP005S), `Strappy Back` (IP006S), `Criss-cross back` (IP001S), `Strappy binding back` (IP002), `Hook clasp back with keyhole cutout` (IP003, IP004S). Necklines: `High Neck`, `Scoop Neck`, `V-Neck`. Every style: `Modified or traditional leg cut`[^gk-ip][^gk-ip005s] |
| GK Elite | UDesign (online 3D studio) | Team controls colours, cuts, fabrics, embellishments; names/logos at set locations in `Spanglez`, crystals/nailheads or embroidery; crystals `Premium Swarovski Crystals` or `Standard Crystals`[^gk-udesign][^gk-9661s] |
| GK Elite | Navigation | `Tank Leotards` (`Show Tanks`, `Replica Leotards`, `Brandable Basics`); `Competition Leotards` (`All Special Order Leotards`, `Infinite Possibilities`, `Special Order Sublimation`, `Stock Competitive Leotards`)[^styles] |
| Sylvia P | Studio SP (3D designer) zones | `Body`, `Inserts & Sleeves`, `Belt`, `Lower Body`, `Straps & Binding`, `Embellishments`[^sylviap-sibella] |
| Sylvia P | Per-order options | `Leg cut` (`Standard`, `Mid Cut`); built-in shelf bra; matching scrunchie (`MATT`, `MYSTIQUE`, `WETLOOK`); `Crystal Coverage` (`Logo Only Standard`, `Light Standard`, `Light Swarovski`, `Heavy Standard`, `Heavy Swarovski`); some listings `Embellishment Options` (`Logo Only Standard`, `Standard Crystals`, `Swarovski Crystals`, `Sequins`)[^sylviap-sibella][^sylviap-cat] |
| Sylvia P | Service tiers | Catalogue design recoloured free; Studio SP self-service; fully custom with design fee[^sylviap-design] |
| Sylvia P | Storefront tags | `Long Sleeve Leotards`, `Sleeveless Leotards`, `Sleeveless Leotards – Complex`; lining variants `Deep Nude Lining`, `Light Nude Lining`[^sylviap-us] |
| Quatro | Lite Range | `Sleeves` (`Sleeveless`, `3 Quarter Length Sleeve`, `Full Sleeve`); `Crystal Types` (`Standard`, `Swarovski`)[^quatro-lite] |
| Quatro | Stones menu | Brands `Swarovski Diamantes`, `DMC Diamantes`, `Standard Diamantes`; shapes `Round`, `Boat`, `Waterdrop`; sizes `SS6`, `SS10`, `SS16`, `SS20`; 21 colours[^quatro-stones] |
| Quatro | Fabrics menu | `LYCRA`, `MYSTIQUE`, `MESH`, `SUBLIMATED LYCRA`, plus three nude tones for lining and mesh[^quatro-fabrics] |
| Quatro | Kit builder | Clubs only, minimum 10[^quatro-studio] |
| Quatro | Navigation | `Short Sleeve`, `Long Sleeve`, `Open Back`, `Workout Tank`, `InStock Competitive`[^quatro-home] |
| Snowflake | Filters | `Category`, `Price`, `Size` only; customisation = free recolour of stock styles or work with a designer[^snowflake-comp] |
| Snowflake | Navigation | Workout `Basic`, `Open Back`, `Tank-Style`, `T-Back`, `Toddler`, `Rhinestone & Deco`; competition `Sleeveless`, `Long Sleeve`, `Value Competition Leotards`[^snowflake-home] |
| Plum | Named training silhouettes (no filters) | `Traditional tank`, `Racerback`, `Asymmetric`, `Keyhole`, `Side panel`, `Mesh cutout`, `Athletic mesh racerback`; menus `Training Leotards`, `Competition Leotards`, `Custom Orders`[^plum] |
| Destira | ReadySetCustom (3 steps) | Pick product, choose fabric, select an embellishment template; retail filters size and price only; navigation `Leotards`, `Unitards`, `Long Sleeve Leos`[^destira-rsc][^destira] |

* **Creation**: [Why the WebGPU view costs more per frame](/engineering/rendering/webgpu-frame-cost-on-windows.md): root-cause hunt on the owner's laptop. The same three.js node shaders are as fast as the WebGL view through three's WebGL 2 backend but 30-40% slower on the GPU through Chromium's WebGPU (Dawn, D3D12); Dawn's IEEE-strict compiling is ~7-10% (a switch only a desktop shell can set); DXC/FXC, robustness, Dawn's D3D11 backend, GPU clocks, draw counts and the stones' storage path ruled out; three's WebGPU renderer costs ~4.5 ms CPU a frame against <1; Edge put WebGPU on the Intel iGPU until forced to the GTX 1650. Dev tool `app/src/dev/pass-times.js`.
